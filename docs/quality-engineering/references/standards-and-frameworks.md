# Standards and Frameworks

A curated list of external standards, frameworks and guidance relevant to Quality Engineering, software testing and AI governance.

These references provide supporting guidance. Their inclusion does not imply formal compliance or certification.

## Software Quality

- [ISO/IEC 25010 — Systems and Software Quality Models](https://www.iso.org/standard/78176.html) — Software product quality model.
- [ISO/IEC/IEEE 29119 — Software Testing](https://www.iso.org/standard/81291.html) — Software testing concepts and processes.

## Requirements and Software Lifecycle

- [ISO/IEC/IEEE 29148 — Requirements Engineering](https://www.iso.org/standard/72089.html) — Requirements engineering processes and practices.
- [ISO/IEC/IEEE 12207 — Software Life Cycle Processes](https://www.iso.org/standard/63712.html) — Software lifecycle processes.

## Testing Knowledge

- [ISTQB — Certified Tester Foundation Level](https://www.istqb.org/certifications/certified-tester-foundation-level) — Software testing principles and terminology.
- [Agile Manifesto](https://agilemanifesto.org/) — Values and principles for Agile software development.

## AI Governance and Risk

- [ISO/IEC 42001 — AI Management Systems](https://www.iso.org/standard/81230.html) — AI management system requirements.
- [ISO/IEC 23894 — AI Risk Management](https://www.iso.org/standard/77304.html) — Guidance for managing AI-related risks.
- [NIST AI Risk Management Framework](https://www.nist.gov/itl/ai-risk-management-framework) — AI risk management guidance.
- [EU AI Act](https://digital-strategy.ec.europa.eu/en/policies/regulatory-framework-ai) — European Union AI regulatory framework.

## Application Security

- [OWASP Top 10](https://owasp.org/www-project-top-ten/) — Common web application security risks.
- [OWASP API Security Top 10](https://owasp.org/www-project-api-security/) — Common API security risks.

---

**Note:** References are provided for guidance and should be checked for current editions and applicability. This framework does not claim formal compliance or certification against these standards.
